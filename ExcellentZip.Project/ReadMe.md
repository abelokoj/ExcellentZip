# ExcellentZip build configuration

Shared native project properties, date-based app versions, and runtime settings live here. The repository uses the pinned Mile.Project.Configurations SDK and NuGet.Config for package restoration.

Build and package Windows x64 with `scripts/Build-Release.ps1`. See `Documents/ExcellentZip.md` for prerequisites and the individual checks. No precompiled custom build-task library is required.
